# INREAIS DELIVERY — Production status

Updated: 2026-11-22

## Editorial scope
- Daily short-form coverage for Brazil, Portugal, the United Kingdom and Ireland.
- Story types: delivery news, controversies/disputes, curious or unusual stories, viral rider posts/videos, first-person experiences, platform/pay/rules changes, safety incidents and worker-rights stories.
- Output: TikTok and YouTube Shorts, vertical 9:16, hard maximum 60 seconds; target 45–55 seconds and approximately 100–130 spoken words.
- Language/voice: Brazilian Portuguese, using the owner's authorised HeyGen voice clone v2.
- The owner remains the final editor. No automatic publishing.

## Components verified in repository
- RSS scout: `scripts/inreais_delivery_scout.py`; searches public Google News RSS for four countries and multiple editorial categories.
- Scheduled workflow: `.github/workflows/inreais-delivery-news-scout.yml`; cron every three hours and manual dispatch.
- Editorial queue/dashboard: `data/inreais-delivery-news.json` (generated by workflow) and `inreais/index.html`.
- Script draft template: `scripts/generate_inreais_script.py`.
- Editorial policy and voice settings: `inreais/editorial-config.json`.

## Execution evidence
- GitHub Actions run #1 completed successfully on 2026-11-22 at 01:15 UTC.
- That run executed the RSS collection and the queue-commit step. The queue file was not present in the repository afterward, revealing a first-run staging bug.
- The workflow was corrected to stage the generated JSON before checking the staged diff. The corrected workflow has not yet had a new run verified. The next scheduled run should validate this fix.
- RSS discovery is not the same as social-platform trend monitoring. Direct automated monitoring of TikTok, Instagram, YouTube, public Facebook pages and Reddit is not implemented.
- The existing script generator creates a structured draft/template, not a fully researched, fact-checked AI script.
- HeyGen voice clone v2 is active in the connected HeyGen workspace; voice generation is available, but the repository workflow is not yet integrated with HeyGen.
- Automated video assembly/rendering, caption timing, and publishing integrations are not implemented.

## Required production gates
1. Open and verify the original source, publication date, country, people and platform.
2. Corroborate important factual claims independently; label allegations and rumours.
3. For personal stories, eyewitness footage and creator-originated claims, seek creator confirmation where appropriate.
4. Never reuse a third-party clip without permission, licence or a documented legal basis. Public visibility is not permission.
5. Use original/appropriately licensed visuals; label AI reconstructions as illustrative.
6. Owner approves story, script, visuals, final edit, title and caption before publication.
