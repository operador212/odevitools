Organizador de transações

Importa um ficheiro CSV do teu banco ou de uma plataforma de entregas para somar entradas e saídas. O ficheiro é processado neste navegador e não é enviado para um servidor por esta ferramenta.

Importante: esta versão é apenas um organizador experimental. Não calcula impostos, não substitui aconselhamento contabilístico e não é o relatório pago de £5,99.

1. Carrega os teus documentos

O importador reconhece o formato de extrato Wise com as colunas Type, Product, Started Date, Completed Date, Description, Amount, Fee, Currency, State e Balance. Também tenta reconhecer CSVs genéricos com amount/valor. Não guardamos nem usamos os teus movimentos reais como dados de exemplo; só usamos a estrutura das colunas.
