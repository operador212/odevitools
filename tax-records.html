As tuas finanças, organizadas.

Importa extratos, acompanha movimentos e revê classificações. O sistema organiza os dados; não transforma automaticamente entradas bancárias em rendimento tributável nem saídas em despesas dedutíveis.

Esta ferramenta está em fase de integração. Os cálculos fiscais oficiais e a submissão de declarações não estão disponíveis.

Configuração necessária

A autenticação ainda não foi configurada pelo administrador. Não introduzas palavras-passe nem dados bancários nesta página até a configuração estar concluída.

Quando o fornecedor OIDC e a API estiverem configurados, o botão Entrar inicia uma sessão segura através de OAuth 2.0 Authorization Code + PKCE.
