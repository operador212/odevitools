Contacto

Encontraste um erro, uma ligação desatualizada ou tens uma sugestão para melhorar o ODEVI+? Podes preparar uma mensagem para a equipa do projeto através do canal público de suporte no GitHub.

Enviar uma sugestão

Preenche o assunto e a mensagem. O botão abre uma nova página de issue no repositório do projeto com o texto preparado; revê a mensagem e envia-a no GitHub se quiseres continuar.

Privacidade: as issues do GitHub são públicas. Não incluas nome completo, morada, email pessoal, números de documentos, dados de imigração, palavras-passe ou outras informações privadas. Para um assunto sensível, não uses este canal público.

Este formulário não envia os dados automaticamente nem os guarda no ODEVI+. A mensagem só é aberta no GitHub depois de tocares no botão; tens de rever e enviar a publicação por tua iniciativa. Poderá ser necessário iniciar sessão no GitHub.
